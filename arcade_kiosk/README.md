# MisterOperator (Arcade Kiosk)

Locked-down, arcade-only frontend for MiSTer cabinets. The full manual is in this folder:
**MANUAL.md**. It's also on GitHub, with screenshots: https://github.com/alex-acsit/MisterOperator

Quick reference:

- Settings: `kiosk.ini` (each setting is explained in the file).
- Hold the OPERATOR button for the operator menu; hold it again to lock.
- Log: `/tmp/arcadekiosk.log`. Status: `python3 arcadekiosk.py --status`.
- Update: operator menu → Update kiosk, or Scripts → update_arcade_kiosk.
